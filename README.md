# MockApp

MockApp is an Android application designed to spoof the GPS location of the device.

## Features
- Enter latitude and longitude coordinates.
- Start and stop mock location spoofing via a Foreground Service.

## Requirements
- Android 7.0 (API 24) or higher.
- Developer Options -> Select mock location app -> MockApp

## How to use
1. Install the APK.
2. Go to Developer Options and set "MockApp" as the mock location app.
3. Open MockApp, enter coordinates, and press "Start Spoofing".
